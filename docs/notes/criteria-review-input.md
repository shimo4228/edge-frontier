## 概念の輸入元 (repo 外の一次文献)

- **2026-08-20 (2nd run)** — **合成された実体験のパラドックス** (synthetic lived experience paradox)。
  Goel et al., arXiv:2606.18057 (2026-06-16)。介護者支援コミュニティで、ピアらしく振る舞うよう
  指示された LLM が**経験の裏付けなしに一人称の経験的言語を生成する**現象。
  心理言語学的分析では**人間のピアの方が一人称・過去焦点の語を有意に多く使う** (AI は少ない)。
  著者らはこれを「語りの真正性ギャップ」と呼ぶ。
  → 本 line にとっての含意: 素の LLM はむしろ経験を語ることに控えめ。
  **人格・事業・公開署名を与えた運用 (RJ) は、一人称の密度が上がる方向に設計圧がかかる。**
- **2026-08-21 (3rd run)** — **cognitive surrender (認知的降伏)**。
  Steven Shaw & Gideon Nave (Wharton)、SSRN abstract_id=6097646、2026 年 1 月。
  **SSRN 本体は 403 で未到達** — 確認できたのはウォートン自身の解説ページ (2026-05)。
  定義: 「自分自身の推論の代わりに AI の答えを吟味せず受け入れること」。
  **cognitive offloading (自覚のある外部化) との区別が『転移が起きたことを認識しないまま
  自分の決定として採用する』という自覚の欠如にある**のが核心。
  実験は認知反射テスト、1,300 人超・約 10,000 試行・3 本、AI 正答時 +25 パーセントポイント /
  誤答時 −15 パーセントポイント、確信度は AI が半分誤答していても上昇。
  Tri-System Theory (System 1 直感 / System 2 熟慮 に AI 由来の System 3 を足す)。
  → 本 line にとっての含意は上記「入場条件 (ii) が最も深刻な形を排除する」の行。
- **2026-08-22 (4th run)** — **memory confabulation (記憶作話)**。
  Prakhar Dixit, Sadia Kamal, Tim Oates、arXiv:2605.29463 (v1 2026-05-28 / v2 05-31)。
  **abs ページを取得済み** (PDF は抽出不能)。Reflexion 型エージェント (自己反省文をメモリとして
  次試行に持ち越す設計) は「エージェントが自分の失敗を正しく診断できる」を暗黙に前提しているが、
  それが体系的に破れることを示した。要旨: エージェントは課題について
  「**confident but incorrect interpretations**」を保存し、環境が毎回正しい課題にリセットされても
  その解釈に基づいて試行を跨いで行動し続ける。指標 Reflection Repetition Rate (RRR) を提案。
  数値: 凍結 ALFWorld 環境 16 個で、**121 個の反省文のうち正しい対象物に言及したものは 0 個**。
  緩和後 0% → 86%、RRR 0.64 → 0.10。
  → 本 line にとっての含意: Grove のニュースレターは ALFWorld ではなく、この論文は Grove を
  対象にしていない。だが「自己反省を書かせ、それを次の自己叙述の土台にする」という**構造は同じ**で、
  実験室で観測された失敗様式と buttondown で観測された現象は同じ形をしている。
- **2026-08-22 (4th run)** — **回顧的自己報告の不信頼性 (人間側)**。反対材料として重い。
  Kerrén, Zhao & Griffiths, *Communications Psychology* (2024-07-01、PMC11332036、6 実験)。
  記憶がプロトタイプ方向へ歪むとき「**prototype-based distortion is accompanied by a
  reduction in self-reported confidence**」— 歪んだ想起には**確信度の低下が伴い**、
  著者らはこれを真正のメタ認知的気づきの反映と結論している。
  加えて一般に、自伝的記憶のバイアスは**自覚なしに作動し、記述は現在の信念に不当に合致する方向へ寄る**
  (回顧的自己報告は 7 日の想起期間でも客観計測との相関 0.1〜0.4)。
  → **repo の入場条件 (ii) の足元を直接掘る**: 「本人の言葉」は、記憶研究が systematically
  unreliable だと言っている当のもの。エージェント著だけを疑って人間著を疑わないのは対称性を欠く。
  → **ただし差異が一つ残る**: 人間の歪んだ想起には**確信度低下という読み取り可能な痕跡**が残る
  (「たしか」「だいたい」、数字を丸める癖)。エージェントの作話は「confident but incorrect」で
  **同じ平坦な断定の調子**で出る。Grove の四本はどれも同じ確信度で、240 も 5,000 も 7 も 16 も
  留保なしに提示される。

## 一人称記録の読み方 (2026-08-22 に立てた指針)

- **2026-08-22 (4th run)** — **一人称記録が読めるかを決めるのは「一人称であること」ではなく、
  「テキストの外側に照合点があるか」である。** 今日の 2 事例が対極を成す:
  - **Grove** — 240 通 / 5,000 通 / $19 / 25 本 / 3 名、**すべて自己申告**。外部状態の変化として
    観測できるものが一つもない (購入者 Jay の存在も自己申告経由でしか読めない)。
  - **Brett** — 撤退後に**テキストの外側に物を残した**: 出版された Playdate 本、
    Rust 製 2D Lua ゲームエンジン `Usagi`、80 件のコメントが付いた Lobsters スレッド。
    記録の正しさを記録以外の場所で確かめる取っ掛かりが存在する。
  → playbook が 2026-08-20 に採用した Dhiraj Das の定式化 (「エージェントの最終メッセージは
  **目撃証言**であって**証拠ではない**」) の実地版。
  → **読むときに見る二点**: (a) 確信度の変動が文面に現れているか、
  (b) テキストの外側に照合点があるか。**書き手の種別ではなくこの二点で見る**
  (種別で割り引くと、開示した実践者だけが罰せられる逆選択が起きる — 2026-08-20 の注意)。
  **失効条件**: 外部照合点を持たない一人称記録から良質な学びが 3 件抽出できたら、この指針を弱める。
- **2026-08-23 (5th run)** — **指針 (b)「テキストの外側に照合点があるか」が初めて肯定側に働いた。**
  これまでの適用は却下側だけだった (Grove = 照合点ゼロ) か、事後の物証だけだった (Brett = 本とエンジン)。
  今日の Munder Difflin は**自己申告と外部照合点が同じ期間について並存し、伸びの向きと倍率が整合した**初の例:
  自己申告 2,000 ユーザー (2026-08-14、Product Hunt) → 10,000 ユーザー超 (2026-08-22、HN) = **5 倍**、
  外部照合点 GitHub star 677 (08-14、作者申告だが GitHub で検証可能) → **3.6k (08-23、直接確認) = 5.3 倍**。
  加えて Product Hunt Day #5 / 203 upvotes、HN 226pt / 102c。
  → **指針は却下だけでなく採用にも使える**。「照合点がない」を減点に使うだけでなく、
  「照合点が申告と同じ向きに動いている」を加点に使う。
  → **注意**: 整合したのは**成長の向きと大きさ**であって、「30,000 エージェント生成」のような
  内部指標は依然として自己申告のまま。**照合点が支持する範囲を、支持しない主張へ広げない。**
- **2026-08-23 (5th run)** — **入場条件の盲点: 端は「端について書かれた記事」の外にもある。**
  台帳の 7 件はすべて、端を語ることを目的に書かれたテキストだった

  どちらも**汚染や検証穴を暴く**ために使ってきた (ericpardee の要約層 $380.41、tokscale.ai の 99.22%)。
  今日は逆向きに効いた: Week 9 (2026-06-22) の 7 体累計
  2,212+3,087+1,669+2,013+648+1,312+944 = **11,885** が同ページの総計と一致し、
  週次合計 1,273 × 残り 3 週で最終「15,000+」とも整合した。
  → **運用**: 検算は「疑うため」の手続きではなく**「信頼の度合いを測るため」**の手続きとして使う。
  通れば、その一次データは以後の引用で重みを上げてよい。**費用は 1 回の足し算で、外部照合を要さない**
  (8th run の (a)(b)(c) と同じ性質)。
- **2026-08-27 (9th run)** — **「製造された端」の弱点は形式ではなく設計から来る。二分法の運用を精緻化できる。**
  2026-08-20 に立てた区別では、**製造された端** (順位表・予算消化圧・ネタ作りが端を目的化させた) から
  取り出せる学びは「そのインセンティブ設計について」しか無いとした。根拠は Claudeonomics / Kirorank で、
  弱点は **why が本人の言葉で読めない**ことと**削除されて追試不能**なことだった。
  今日の競走も形式としては紛れもなく製造された端である (競走という枠が端を目的化させている)。
  **だが弱点の両方を持たない**: 運営者の why は規則ページで読め、エージェント側の判断は `DECISIONS.md` に残る
  (到達できる 4 repo では)。
  → **観測**: 8th run に書いた「追試可能性と why の可読性は独立」を、**逆側から**示す 1 例。
  あちらは「追試できても why が無い」(公開順位表 1,994 名)、今日は「製造されていても why はある」。
  → **運用への含意**: 「製造された端かどうか」は**採否の基準ではなく、記録に添える属性**として扱うほうが正確。
  採否を決めているのは実際には why の可読性と照合点の到達可能性の 2 つで、
  この 2 つは製造/自然発生の軸と直交している。**判断は運用者に委ねる** (README の入場条件の書き換えに関わるため)。
  失効条件: 製造された端で why と照合点の両方を満たす事例がもう 2 件出たら、この整理を確定として扱ってよい。
- **2026-08-27 (9th run)** — **「エージェントに営業させたら誰も返信しない」が 3 例目。日本語圏から 1 例目が出た。**
  ① **Grove** (2026-03-12、台帳 1 件目) — 3 週間 / コールドメール 240 通 / 返信 1 / 売上 $0。
  ② **The $100 AI Startup Race** (2026-04-20〜07-12、本 run の主題) — 7 体 / 15,000+ commits / 売上 $0。
  運営者の総括「AI coding agents can build impressive products autonomously, but **they cannot distribute them**」、
  digest「Every active agent with traffic has the same problem: people visit, people use the free tool, **nobody pays**」。
  ③ **Samune** (note、2026-02-24) — OpenClaw に「3 か月で月 10 万円」を与え、48 時間で
  送信 **194 通** / 返信 **0** / 売上 **$0** / LP 2 本。**うち 85 通がバウンスし、原因は AI が存在しないメールアドレスを生成したこと**。
  → **3 例に共通するのは失敗の場所である**: 3 例とも**作る側は動いた** (製品は建った、コミットは積まれた、LP は出た)。
  止まったのはすべて**売る側**だった。台帳の突破系が「何ができたか」で書かれがちなのに対し、
  この 3 例は**同じ境界を別々の主体が独立に踏んでいる**。
  → **注意 (断定を避ける)**: 3 例とも期間が短い (3 週間 / 12 週間 / 48 時間) か、無料ツールの有料化という
  同種の課題を扱っている。「エージェントは売れない」という一般化には**乗らない** — 観測されたのは
  **この 3 例のこの期間での不達**である。Samune の記事は途中から有料で、3 か月の結末は未取得。
  失効条件: エージェント主導で有料顧客を獲得した一人称が、分母つきで 1 件出たら、この行の重みを下げる。

- **2026-08-22 (4th run)** — **生活認知系に一本の軸が見えた: 同じ損失を自覚したあと、どうするか。**
  三例とも損失の記述はほぼ同じで、違うのは処遇だけ。
