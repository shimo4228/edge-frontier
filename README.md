# edge-frontier

AI 活用を常識外の強度・範囲まで push している「スーパーエッジケース」の観測と思索の記録。学術研究ではなく、実践者の定点観測。分布の端(エッジ)にこそ、平均的な活用からは見えない学びが先に現れるという仮説で運営する。

観測の主流入は daily-research の `edge` line(毎日実行)。

## 3 本柱(初期の見取り図)

| 柱 | 何を観測するか | 置き場 |
|---|---|---|
| 突破系(成功エッジ) | 数十並列エージェント運用・月数千ドル級のトークン消費・AI だけで回す事業や製品など、常識外の規模・手法で成果を出している一人称事例 | cases.md |
| 崩壊系(失敗エッジ) | やりすぎの果ての failure mode — 技能退化、AI 依存の破綻、極端運用が壊れた事後検証(post-mortem) | cases.md |
| 生活・認知系エッジ | 開発以外の極端活用 — 生活の意思決定・人間関係・思考の全面 AI 委譲と、それによる人間側の変容の一人称記録 | cases.md |

## 隣接領域との境界(2026-08-20)

- **desire-frontier との境界**: desire は「AI に頼みたいことが尽きた後」の需要側(欲望・虚無)を観測する。edge は「活用強度の極端点」でいま起きていることと、そこから何が学べるかを観測する。崩壊系の証言が枯渇型(頼みたいことが尽きた)なら desire-frontier の testimonies へ回し、こちらの台帳には持たない
- 新ツール紹介・ベンチマーク・平均的な活用 Tips は対象外 — 分布の端であることが入場条件
- 有名事例の再確認(裏付け)は成果ではない — 台帳の前提を動かす新種のエッジを探す

## 観測ループ

daily-research の `edge` line が毎日(daily = true、daily-research ADR-0013)この repo を cwd に外部観測し、レポートを Obsidian vault へ出す。発見の台帳への還元(cases.md / reading-list.md / README)は運用者が手動 ingest で行う。エッジ事例が見つからない日も baseline データ。
